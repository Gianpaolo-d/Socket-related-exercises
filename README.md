# Socket-related exercises

This repository contains a set of progressively improved networking exercises focused on TCP/UDP communication in Python.

## Exercises

- **exercise-0**: Refactoring and modularization of the initial TCP/UDP ping-pong clients/servers.
- **exercise-1**: UDP server enhancement with a persistent (only in runtime) counter included in the reply.
- **exercise-2**: TCP server upgraded to support multiple clients concurrently.
- **exercise-3**: UDP unreliable channel simulation (packet loss) with client timeout handling.
- **exercise-4**: Minimal TCP chat application.
